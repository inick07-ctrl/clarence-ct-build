# Clarence Ct Build Tracker

iOS-style home-build tracker (PWA) for Nick’s Clarence Ct project (Stearns County).

- **Build site:** Lot **28630** only
- **ROFR option:** Lot **28642** (contingent — not the house site)
- **Plan:** **U13** — 2,636 sf living · 900 garage · 144 gym · 60 utilities
- **Land:** $55k close Jan 15, 2027 · ROFR $45k contingent
- **Base cap:** $350k (editable; land include toggle)
- **Start:** Spring (April) 2027

Static single-page app. Edits persist in the browser (`localStorage` v7) with JSON export/import. Add to Home Screen for a full-screen app.

Live: https://inick07-ctrl.github.io/clarence-ct-build/
